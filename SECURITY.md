# Security

Do not open a public issue for a suspected vulnerability.

Report security issues through Ledger's coordinated disclosure process at
[donjon.ledger.com/bounty](https://donjon.ledger.com/bounty/). Include the
affected SDK version, impact, reproduction steps, and any suggested mitigation.

Never include real secret keys, credentials, access tokens, authentication
cookies, or customer data in a report or test case.
